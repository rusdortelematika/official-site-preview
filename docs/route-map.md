# Тестовая карта ЮЛА

Компонент: `src/components/home/RouteMap/RouteMap.tsx` и соседний CSS-модуль.
На главной подключён после тарифов через `client:visible`. MapLibre и данные
загружаются при приближении к блоку. Подложка — OpenFreeMap Bright, ключ API не нужен.

## Редактирование данных

Файлы находятся в `public/data/map`. Компонент запрашивает их без кеширования
браузером при каждом создании карты, поэтому менять координаты можно без изменения TSX.
Для статического хостинга обновлённые файлы нужно опубликовать. При наличии CDN
учитывайте его собственные правила кеширования.

Все координаты записываются в порядке **[долгота, широта]**, в градусах WGS84.

- `road.geojson` — геометрия ЮЛА: GeoJSON FeatureCollection с LineString или
  MultiLineString. В тесте использованы именованные действующие участки из
  OpenStreetMap. Это исходные данные для прототипа; для запуска их можно заменить
  утверждённой геометрией оператора.
- `gantries.json` — объект с `version: 1` и массивом `items`. Каждая рамка имеет
  уникальный `id`, `coordinates`, `label.ru` и `label.en`. У тестовых точек
  стоит `test: true`; в карточке показывается соответствующая подпись.
  Чтобы добавить рамку, добавьте ещё один объект в `items`.
- `alternatives.geojson` — GeoJSON FeatureCollection с альтернативами. В свойствах
  каждого маршрута есть `id`, `label.ru`, `label.en`, `color` и `distanceKm`.
  Кнопка показывает или скрывает альтернативный маршрут, сохраняя ЮЛА.

Пример рамки:

```json
{
  "id": "gantry-01",
  "coordinates": [37.6445352, 55.5351821],
  "label": { "ru": "Рамка 01", "en": "Gantry 01" },
  "test": true
}
```

При замене на реальные координаты уберите `test` или установите `false`.
Точки остаются привязаны к географическим координатам при изменении масштаба,
перетаскивании и изменении размера окна.

## Поведение

- Кнопка ЮЛА скрывает альтернативы и возвращает обзор основной дороги.
- Кнопка альтернатив переключает один сохранённый тестовый путь через МКАД
  и Люберцы (коричневая линия). Геометрия получена из OSRM; промежуточные точки
  заданы на сквозных участках дорог, без заездов к тупикам и съездам.
  Маршрут требует проверки оператором перед публикацией в качестве официальной
  бесплатной альтернативы: сервис не гарантировал исключение всех платных дорог.
- Во время просмотра посетителем расчёт маршрутов и обращения к OSRM не выполняются.
- Кнопки +/−, вертикальный ползунок, жесты и клавиатура меняют масштаб.
  Прокрутка страницы над картой сохраняется; для масштабирования колесом
  используется Ctrl (Windows/Linux) или ⌘ (macOS).
- Нажатие на рамку открывает название и координаты. Доступно с клавиатуры.
- RU/EN меняет интерфейс, подписи рамок и язык названий на подложке, когда
  соответствующий перевод есть в OpenStreetMap.
- При ошибке загрузки доступна кнопка повторной попытки.

## Источники

- Геометрия дороги и картографические данные:
  [OpenStreetMap](https://www.openstreetmap.org/copyright).
- Подложка: [OpenFreeMap](https://openfreemap.org/).
- Библиотека: [MapLibre GL JS](https://maplibre.org/maplibre-gl-js/docs/).
- Подготовка тестовых объездов:
  [OSRM](https://routing.openstreetmap.de/).

Атрибуция OpenStreetMap, OpenMapTiles и OpenFreeMap сохраняется на карте.
Изображения и SVG компонента находятся в `src/assets/pages/home/map`;
оригинальная иконка маршрута переиспользуется из `src/assets/icons/home/route.svg`.
